# Clean-flow 예상 운영 비용 보고서

본 문서는 100개 병원 및 20명의 수거 기사가 시스템을 매일 사용할 경우를 가정한 Firebase 기반의 예상 월 운영 비용입니다.

## 1. 전제 조건
- **병원 수**: 100개 거점 (일일 평균 1회 수거 요청)
- **기사 수**: 20명 (일일 평균 5개 거점 방문)
- **공정 수**: 월간 약 3,000건의 세탁 요청 처리
- **데이터 보존**: 텍스트 로그 및 단계별 수량 대조 데이터

## 2. 서비스별 상세 분석 (월간 기준)

### Cloud Firestore (데이터베이스)
- **쓰기 (Writes)**: 요청 1건당 공정 단계별 약 30회 업데이트 발생.
  - 3,000건 * 30회 = 90,000회 (무료 티어 범위 내)
- **읽기 (Reads)**: 실시간 모니터링 및 대시보드 조회.
  - 월 약 600,000회 예상 (무료 티어 범위 내)
- **저장소**: 수만 건의 텍스트 데이터 저장 시에도 1GB 미만.
- **예상 비용**: **$0 (무료)**

### Firebase Authentication (사용자 인증)
- MAU(월간 활성 사용자) 약 200명.
- **예상 비용**: **$0 (월 5만 명까지 무료)**

### Cloud Storage (이미지 저장 - 차이 발생 증빙용)
- 한 달에 약 300장의 증빙 사진 업로드 가정 (장당 1MB).
- 월 약 300MB ~ 1GB 누적.
- **예상 비용**: **약 $0.50 (한화 약 700원)**

### Gemini AI (분쟁 조율 엔진)
- 월 300회의 AI 분석 실행.
- Gemini 1.5 Flash 모델 사용 시.
- **예상 비용**: **약 $1.00 미만 (호출량에 따라 무료 가능)**

## 3. 총평
- **합계 예상 비용**: **월 $0 ~ $5 (약 0원 ~ 7,000원)**
- Clean-flow는 텍스트 데이터 중심의 구조이므로 Firebase의 무료 티어 활용도가 매우 높습니다. 
- 향후 병원 수가 1,000개 이상으로 확장되더라도 인프라 비용은 매출 대비 극히 낮은 수준(월 5만 원 미만)으로 유지될 수 있는 경제적인 아키텍처입니다.

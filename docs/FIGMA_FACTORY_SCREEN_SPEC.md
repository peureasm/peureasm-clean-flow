# Figma Factory Screen Spec

## 목적
- 공장 역할에 최적화된 UI를 피그마에서 바로 설계할 수 있도록 화면별 명세를 정리한다.
- 현재 코드베이스의 공장 라우트를 기준으로, 입고 확인, 공정 진행, 출고 처리, 수량 차이 대응이 가장 빠르게 이루어지도록 UX 구조를 정의한다.

## 대상 라우트
- `/factory`
- `/factory/inbound`
- `/factory/inbound/[id]`
- `/factory/outbound`
- `/factory/outbound/[id]`

## 공장 UX 핵심 원칙
- 공정 단계를 한눈에 보여준다.
- 수량과 예외 정보가 텍스트보다 먼저 보여야 한다.
- 입고와 출고는 서로 다른 흐름으로 명확히 구분한다.
- 현장 작업자는 빠르게 확인하고 다음 단계로 넘길 수 있어야 한다.
- 차이 발생 시 원인 파악보다 "즉시 표시"가 먼저다.

## 공장 공통 레이아웃 규칙

### 기본 구조
- 상단 제목 + 설명
- 중간 KPI 카드
- 아래 작업 큐
- 상세에서는 `요약 -> 수량 비교 -> 공정 액션`

### 상태 우선순위
- 입고 대기
- 세탁 중
- 건조 중
- 포장 완료
- 출고 대기

### 액션 원칙
- `입고 확인`
- `공정 시작`
- `출고 준비 완료`
- `출고 완료`

한 화면에서 주액션 1개만 가장 크게 둔다.

## Screen 1. 공장 홈

### 화면 목적
- 현재 공정 병목과 오늘 처리량을 한눈에 보여준다.

### KPI 카드
- 입고 대기 건수
- 세탁 중 건수
- 출고 대기 건수
- 차이 발생 건수

### 메인 섹션
- `즉시 처리할 큐`
  - 입고 대기
  - 차이 발생
  - 출고 대기
- `공정 흐름 보드`
  - 단계별 건수

### 피그마 포인트
- 관리자 대시보드보다 더 현장형이어야 한다.
- 숫자와 단계 구조가 가장 먼저 보여야 한다.

## Screen 2. 입고 대기 목록

### 화면 목적
- 병원에서 넘어온 수거 요청을 공장에서 입고 확인한다.

### 상단 필터
- 전체
- 신규
- 차이 발생 예상
- 지연 건

### 리스트 정보
- 병원명
- 요청일
- 기사 확인 수량
- 현재 상태
- 상세 진입

### UI 제안
- 테이블보다 카드형 리스트 + 우측 핵심 수량 배지 조합 추천

### 피그마 포인트
- 현장 작업자는 스캔 속도가 중요하므로 병원명/수량/상태를 크게

## Screen 3. 입고 상세

### 화면 목적
- 기사 확인 수량과 공장 실제 입고 수량을 비교하고 입고를 확정한다.

### 상단
- 병원명
- 요청일
- 상태 배지
- 작업 진행 상태

### 메인 구조
- 품목별 비교 리스트
  - 품목명
  - 기사 확인 수량
  - 공장 입고 수량 입력
  - 차이 여부

### 보조 영역
- 차이 발생 요약 카드
- 특이사항 메모

### 하단 CTA
- 임시 저장
- 입고 확인 완료

### 피그마 포인트
- 표보다는 비교 카드형 또는 2열 수량 비교형 추천
- 차이 발생 행은 색상과 아이콘으로 명확히

## Screen 4. 출고 대기 목록

### 화면 목적
- 세탁 완료 후 병원 납품 전 단계 요청을 관리한다.

### 상단 필터
- 전체
- 오늘 출고
- 대기 중
- 지연 건

### 리스트 정보
- 병원명
- 요청일
- 출고 예정 수량
- 상태
- 상세 보기

### 피그마 포인트
- 입고 목록과 동일한 계열이지만 상태색과 의미를 다르게
- 출고 단계는 더 정돈된 리스트형이 적합

## Screen 5. 출고 상세

### 화면 목적
- 최종 출고 수량을 확인하고 기사 또는 병원 납품 흐름으로 넘긴다.

### 상단
- 병원명
- 요청일
- 현재 상태

### 메인 구조
- 품목별 수량 정보
  - 공장 입고 수량
  - 출고 수량 입력
  - 차이 여부
- 최종 출고 수량 합계

### 하단 CTA
- 출고 확정

### 보조 정보
- 특이사항
- 출고 시각 기록

### 피그마 포인트
- 출고 단계는 “최종 확인” 느낌이 강해야 한다.
- 수량 입력 후 확정 버튼까지 동선이 짧아야 한다.

## 공장 역할 디자인 톤
- 깔끔하고 기능적인 작업 대시보드
- 블루/그레이 베이스에 경고색은 제한적으로 사용
- 숫자와 상태를 크게, 설명은 작게
- 카드 간 계층을 명확히 해 스캔 속도 향상

3. 공장 홈
4. 입고 목록
5. 출고 목록

## 개발 반영 시 주의점
- 수량 비교는 항상 동일한 컬럼 순서와 레이블을 유지한다.
- 차이 발생 여부는 색상에만 의존하지 않고 텍스트/아이콘도 함께 사용한다.
- 공장 상세 화면의 CTA는 하단 고정 구성이 적합하다.
- 공정 상태 표현은 관리자 상태 배지와 호환되되, 공장 화면에서 더 직관적으로 보여야 한다.
